因為很常需要裁切圖片當 wallpaper，預覽程式沒那麼方便，開 PS 又有點殺雞牛刀。所以就用 AI 開發了一個小 App

手頭上還有兩個 mobile app 在開發，但是這個需求很小，大概一個晚上邊追劇邊跟 claude 聊聊就作完了

讓 Claude code 編寫 SwiftUI code、chatGPT 產生 App icon 看一看沒問題就準備送審了

中間花最多的時間大概就是申請新的 Apple ID，舊的 Apple ID 莫名原因被鎖了。打了客服也無解，然後用我的手機兩個號碼去申請帳號也申請不過，直到某天去朋友家臨時界朋友的手機號碼才申請過，Apple Account 的整個建立流程真的是...爛！

App 預覽圖也是用 claude code 去產生的，中間只改了一版，大概確認也就用了，本來就不是很認真的 App，我連隱私權頁面相關需要 web page 的部分全部用 Notion 處理 😆

初審時間大約一週，上週二送，今天一樣週二的凌晨收到通過的信件通知。真的挺意外的，本來想說要等著被退然後要再上一版

挺有意思的一次經驗，或許哪天臨時想到一個小的應用我會依樣畫葫蘆再來作一個 😎

現在最想做的是 D&D 跑團相關的應用，最近參加了兩次跑團實在是很有趣，但是有些繁瑣的事情其實有一個方便的 App 真的會方便很多
